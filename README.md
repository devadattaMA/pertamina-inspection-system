# PHM Intelligence — Frontend Prototype

A frontend-only prototype for a centralized inspection, corrosion, production-data and asset-integrity workspace.

## Stack
- Next.js App Router
- React + TypeScript
- Lucide React
- Custom CSS

## Run locally
```bash
npm install
npm run dev
```

## Notes
- All dashboard values and asset records are illustrative sample data, not live Pertamina information.
- Authentication, database persistence, source-system integrations (SAP, Direct Viewer and pipeline database), imports, exports and reporting workflows are not connected yet.
- The initial prototype focuses on the overview dashboard, navigation, department filter and asset search.
